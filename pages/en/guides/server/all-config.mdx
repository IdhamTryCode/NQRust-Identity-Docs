# All configuration

## Cache

| Option | _Type_ or Values | Default |
| --- | --- | --- |
| **`cache`**<br/>Defines the cache mechanism for high-availability.<br/>By default in production mode, a `ispn` cache is used to create a cluster between multiple server nodes. By default in development mode, a `local` cache disables clustering and is intended for development and testing purposes.<br/>**CLI:** `--cache`<br/>**Env:** `KC_CACHE` | `ispn`, `local` |  |
| **`cache-config-file`**<br/>Defines the file from which cache configuration should be loaded from.<br/>The configuration file is relative to the `conf/` directory.<br/>**CLI:** `--cache-config-file`<br/>**Env:** `KC_CACHE_CONFIG_FILE` | _File_ |  |
| **`cache-config-mutate`**<br/>Determines whether changes to the default cache configurations are allowed.<br/>This is only recommended for advanced use-cases where the default cache configurations are proven to be problematic. The only supported way to change the default cache configurations is via the other `cache-…​` options.<br/>**CLI:** `--cache-config-mutate`<br/>**Env:** `KC_CACHE_CONFIG_MUTATE` | `true`, `false` | `false` |
| **`cache-embedded-authorization-max-count`**<br/>The maximum number of entries that can be stored in-memory by the authorization cache.<br/>**CLI:** `--cache-embedded-authorization-max-count`<br/>**Env:** `KC_CACHE_EMBEDDED_AUTHORIZATION_MAX_COUNT` | _Integer_ |  |
| **`cache-embedded-client-sessions-max-count`**<br/>The maximum number of entries that can be stored in-memory by the clientSessions cache.<br/>**CLI:** `--cache-embedded-client-sessions-max-count`<br/>**Env:** `KC_CACHE_EMBEDDED_CLIENT_SESSIONS_MAX_COUNT` | _Integer_ |  |
| **`cache-embedded-crl-max-count`**<br/>The maximum number of entries that can be stored in-memory by the crl cache.<br/>**CLI:** `--cache-embedded-crl-max-count`<br/>**Env:** `KC_CACHE_EMBEDDED_CRL_MAX_COUNT` | _Integer_ |  |
| **`cache-embedded-keys-max-count`**<br/>The maximum number of entries that can be stored in-memory by the keys cache.<br/>**CLI:** `--cache-embedded-keys-max-count`<br/>**Env:** `KC_CACHE_EMBEDDED_KEYS_MAX_COUNT` | _Integer_ |  |
| **`cache-embedded-mtls-enabled`**<br/>Encrypts the network communication between NQRust-Identity servers.<br/>If no additional parameters about a keystore and truststore are provided, ephemeral key pairs and certificates are created and rotated automatically, which is recommended for standard setups.<br/>**CLI:** `--cache-embedded-mtls-enabled`<br/>**Env:** `KC_CACHE_EMBEDDED_MTLS_ENABLED` | `true`, `false` | `true` |
| **`cache-embedded-mtls-key-store-file`**<br/>The Keystore file path.<br/>The Keystore must contain the certificate to use by the TLS protocol. By default, it looks up `cache-mtls-keystore.p12` under conf/ directory.<br/>**CLI:** `--cache-embedded-mtls-key-store-file`<br/>**Env:** `KC_CACHE_EMBEDDED_MTLS_KEY_STORE_FILE` | _String_ |  |
| **`cache-embedded-mtls-key-store-password`**<br/>The password to access the Keystore.<br/>**CLI:** `--cache-embedded-mtls-key-store-password`<br/>**Env:** `KC_CACHE_EMBEDDED_MTLS_KEY_STORE_PASSWORD` | _String_ |  |
| **`cache-embedded-mtls-rotation-interval-days`**<br/>Rotation period in days of automatic JGroups MTLS certificates.<br/>**CLI:** `--cache-embedded-mtls-rotation-interval-days`<br/>**Env:** `KC_CACHE_EMBEDDED_MTLS_ROTATION_INTERVAL_DAYS` | _Integer_ | `30` |
| **`cache-embedded-mtls-trust-store-file`**<br/>The Truststore file path.<br/>It should contain the trusted certificates or the Certificate Authority that signed the certificates. By default, it lookup `cache-mtls-truststore.p12` under conf/ directory.<br/>**CLI:** `--cache-embedded-mtls-trust-store-file`<br/>**Env:** `KC_CACHE_EMBEDDED_MTLS_TRUST_STORE_FILE` | _String_ |  |
| **`cache-embedded-mtls-trust-store-password`**<br/>The password to access the Truststore.<br/>**CLI:** `--cache-embedded-mtls-trust-store-password`<br/>**Env:** `KC_CACHE_EMBEDDED_MTLS_TRUST_STORE_PASSWORD` | _String_ |  |
| **`cache-embedded-network-bind-address`**<br/>IP address used by clustering transport.<br/>By default, SITE_LOCAL is used.<br/>**CLI:** `--cache-embedded-network-bind-address`<br/>**Env:** `KC_CACHE_EMBEDDED_NETWORK_BIND_ADDRESS` | _String_ |  |
| **`cache-embedded-network-bind-port`**<br/>The Port the clustering transport will bind to.<br/>By default, port 7800 is used.<br/>**CLI:** `--cache-embedded-network-bind-port`<br/>**Env:** `KC_CACHE_EMBEDDED_NETWORK_BIND_PORT` | _Integer_ |  |
| **`cache-embedded-network-external-address`**<br/>IP address that other instances in the cluster should use to contact this node.<br/>Set only if it is different to cache-embedded-network-bind-address, for example when this instance is behind a firewall.<br/>**CLI:** `--cache-embedded-network-external-address`<br/>**Env:** `KC_CACHE_EMBEDDED_NETWORK_EXTERNAL_ADDRESS` | _String_ |  |
| **`cache-embedded-network-external-port`**<br/>Port that other instances in the cluster should use to contact this node.<br/>Set only if it is different to cache-embedded-network-bind-port, for example when this instance is behind a firewall<br/>**CLI:** `--cache-embedded-network-external-port`<br/>**Env:** `KC_CACHE_EMBEDDED_NETWORK_EXTERNAL_PORT` | _Integer_ |  |
| **`cache-embedded-offline-client-sessions-max-count`**<br/>The maximum number of entries that can be stored in-memory by the offlineClientSessions cache.<br/>**CLI:** `--cache-embedded-offline-client-sessions-max-count`<br/>**Env:** `KC_CACHE_EMBEDDED_OFFLINE_CLIENT_SESSIONS_MAX_COUNT` | _Integer_ |  |
| **`cache-embedded-offline-sessions-max-count`**<br/>The maximum number of entries that can be stored in-memory by the offlineSessions cache.<br/>**CLI:** `--cache-embedded-offline-sessions-max-count`<br/>**Env:** `KC_CACHE_EMBEDDED_OFFLINE_SESSIONS_MAX_COUNT` | _Integer_ |  |
| **`cache-embedded-realms-max-count`**<br/>The maximum number of entries that can be stored in-memory by the realms cache.<br/>**CLI:** `--cache-embedded-realms-max-count`<br/>**Env:** `KC_CACHE_EMBEDDED_REALMS_MAX_COUNT` | _Integer_ |  |
| **`cache-embedded-sessions-max-count`**<br/>The maximum number of entries that can be stored in-memory by the sessions cache.<br/>**CLI:** `--cache-embedded-sessions-max-count`<br/>**Env:** `KC_CACHE_EMBEDDED_SESSIONS_MAX_COUNT` | _Integer_ |  |
| **`cache-embedded-users-max-count`**<br/>The maximum number of entries that can be stored in-memory by the users cache.<br/>**CLI:** `--cache-embedded-users-max-count`<br/>**Env:** `KC_CACHE_EMBEDDED_USERS_MAX_COUNT` | _Integer_ |  |
| **`cache-metrics-histograms-enabled`**<br/>Enable histograms for metrics for the embedded caches.<br/>**CLI:** `--cache-metrics-histograms-enabled`<br/>**Env:** `KC_CACHE_METRICS_HISTOGRAMS_ENABLED` | `true`, `false` | `false` |
| **`cache-remote-backup-sites`**<br/>Configures a list of backup sites names to where the external Infinispan cluster backups the NQRust-Identity data.<br/>**CLI:** `--cache-remote-backup-sites`<br/>**Env:** `KC_CACHE_REMOTE_BACKUP_SITES` | _List_ |  |
| **`cache-remote-host`**<br/>The hostname of the external Infinispan cluster.<br/>Available only when feature `multi-site` or `clusterless` is set.<br/>**CLI:** `--cache-remote-host`<br/>**Env:** `KC_CACHE_REMOTE_HOST` | _String_ |  |
| **`cache-remote-password`**<br/>The password for the authentication to the external Infinispan cluster.<br/>It is optional if connecting to an unsecure external Infinispan cluster. If the option is specified, `cache-remote-username` is required as well.<br/>**CLI:** `--cache-remote-password`<br/>**Env:** `KC_CACHE_REMOTE_PASSWORD` | _String_ |  |
| **`cache-remote-port`**<br/>The port of the external Infinispan cluster.<br/>**CLI:** `--cache-remote-port`<br/>**Env:** `KC_CACHE_REMOTE_PORT` | _Integer_ | `11222` |
| **`cache-remote-tls-enabled`**<br/>Enable TLS support to communicate with a secured remote Infinispan server.<br/>Recommended to be enabled in production.<br/>**CLI:** `--cache-remote-tls-enabled`<br/>**Env:** `KC_CACHE_REMOTE_TLS_ENABLED` | `true`, `false` | `true` |
| **`cache-remote-username`**<br/>The username for the authentication to the external Infinispan cluster.<br/>It is optional if connecting to an unsecure external Infinispan cluster. If the option is specified, `cache-remote-password` is required as well.<br/>**CLI:** `--cache-remote-username`<br/>**Env:** `KC_CACHE_REMOTE_USERNAME` | _String_ |  |
| **`cache-stack`**<br/>Define the default stack to use for cluster communication and node discovery.<br/>Defaults to `jdbc-ping` if not set.<br/>**CLI:** `--cache-stack`<br/>**Env:** `KC_CACHE_STACK` | `jdbc-ping`, `kubernetes` (deprecated), `jdbc-ping-udp` (deprecated), `tcp` (deprecated), `udp` (deprecated), `ec2` (deprecated), `azure` (deprecated), `google` (deprecated), or any |  |

## Database

| **`db-driver`**<br/>The fully qualified class name of the JDBC driver.<br/>If not set, a default driver is set accordingly to the chosen database.<br/>**Named key:** `db-driver-<datasource>`<br/>**CLI:** `--db-driver`<br/>**Env:** `KC_DB_DRIVER` | _String_ |  |
| **`db-log-slow-queries-threshold`**<br/>Log SQL statements slower than the configured threshold with logger org.<br/>hibernate.SQL_SLOW and log-level info.<br/>**Named key:** `db-log-slow-queries-threshold-<datasource>`<br/>**CLI:** `--db-log-slow-queries-threshold`<br/>**Env:** `KC_DB_LOG_SLOW_QUERIES_THRESHOLD` | _Integer_ | `10000` |
| **`db-password`**<br/>The password of the database user.<br/>**Named key:** `db-password-<datasource>`<br/>**CLI:** `--db-password`<br/>**Env:** `KC_DB_PASSWORD` | _String_ |  |
| **`db-pool-initial-size`**<br/>The initial size of the connection pool.<br/>**Named key:** `db-pool-initial-size-<datasource>`<br/>**CLI:** `--db-pool-initial-size`<br/>**Env:** `KC_DB_POOL_INITIAL_SIZE` | _Integer_ |  |
| **`db-pool-max-lifetime`**<br/>The maximum time a connection remains in the pool, after which it will be closed upon return and replaced as necessary.<br/>May be an ISO 8601 duration value, an integer number of seconds, or an integer followed by one of [ms, h, m, s, d].<br/>**CLI:** `--db-pool-max-lifetime`<br/>**Env:** `KC_DB_POOL_MAX_LIFETIME` | _String_ |  |
| **`db-pool-max-size`**<br/>The maximum size of the connection pool.<br/>**Named key:** `db-pool-max-size-<datasource>`<br/>**CLI:** `--db-pool-max-size`<br/>**Env:** `KC_DB_POOL_MAX_SIZE` | _Integer_ | `100` |
| **`db-pool-min-size`**<br/>The minimal size of the connection pool.<br/>**Named key:** `db-pool-min-size-<datasource>`<br/>**CLI:** `--db-pool-min-size`<br/>**Env:** `KC_DB_POOL_MIN_SIZE` | _Integer_ |  |
| **`db-schema`**<br/>The database schema to be used.<br/>**Named key:** `db-schema-<datasource>`<br/>**CLI:** `--db-schema`<br/>**Env:** `KC_DB_SCHEMA` | _String_ |  |
| **`db-tls-mode`**<br/>Sets the TLS mode for the database connection.<br/>If disabled, it uses the driver’s default value. When set to verify-server, it enables encryption and server identity verification. The database server certificate or Certificate Authority (CA) certificate is required.<br/>**Named key:** `db-tls-mode-<datasource>`<br/>**CLI:** `--db-tls-mode`<br/>**Env:** `KC_DB_TLS_MODE` | `disabled`, `verify-server` | `disabled` |
| **`db-tls-trust-store-file`**<br/>The path to the truststore file containing the database server certificates or Certificate Authority (CA) certificates used to verify the database server’s identity.<br/>**Named key:** `db-tls-trust-store-file-<datasource>`<br/>**CLI:** `--db-tls-trust-store-file`<br/>**Env:** `KC_DB_TLS_TRUST_STORE_FILE` | _File_ |  |
| **`db-tls-trust-store-password`**<br/>The password to access the truststore file specified in db-tls-trust-store-file (if required and supported by the JDBC driver).<br/>**Named key:** `db-tls-trust-store-password-<datasource>`<br/>**CLI:** `--db-tls-trust-store-password`<br/>**Env:** `KC_DB_TLS_TRUST_STORE_PASSWORD` | _String_ |  |
| **`db-tls-trust-store-type`**<br/>The type of the truststore file.<br/>Common values include `JKS` (Java KeyStore) and `PKCS12`. If not specified, it uses the driver’s default.<br/>**Named key:** `db-tls-trust-store-type-<datasource>`<br/>**CLI:** `--db-tls-trust-store-type`<br/>**Env:** `KC_DB_TLS_TRUST_STORE_TYPE` | _String_ |  |
| **`db-url`**<br/>The full database JDBC URL.<br/>If not provided, a default URL is set based on the selected database vendor. For instance, if using `postgres`, the default JDBC URL would be `jdbc:postgresql://localhost/keycloak`.<br/>**Named key:** `db-url-full-<datasource>`<br/>**CLI:** `--db-url`<br/>**Env:** `KC_DB_URL` | _String_ |  |
| **`db-url-database`**<br/>Sets the database name of the default JDBC URL of the chosen vendor.<br/>If the `db-url` option is set, this option is ignored.<br/>**Named key:** `db-url-database-<datasource>`<br/>**CLI:** `--db-url-database`<br/>**Env:** `KC_DB_URL_DATABASE` | _String_ |  |
| **`db-url-host`**<br/>Sets the hostname of the default JDBC URL of the chosen vendor.<br/>If the `db-url` option is set, this option is ignored.<br/>**Named key:** `db-url-host-<datasource>`<br/>**CLI:** `--db-url-host`<br/>**Env:** `KC_DB_URL_HOST` | _String_ |  |
| **`db-url-port`**<br/>Sets the port of the default JDBC URL of the chosen vendor.<br/>If the `db-url` option is set, this option is ignored.<br/>**Named key:** `db-url-port-<datasource>`<br/>**CLI:** `--db-url-port`<br/>**Env:** `KC_DB_URL_PORT` | _Integer_ |  |
| **`db-url-properties`**<br/>Sets the properties of the default JDBC URL of the chosen vendor.<br/>Make sure to set the properties accordingly to the format expected by the database vendor, as well as appending the right character at the beginning of this property value. If the `db-url` option is set, this option is ignored.<br/>**Named key:** `db-url-properties-<datasource>`<br/>**CLI:** `--db-url-properties`<br/>**Env:** `KC_DB_URL_PROPERTIES` | _String_ |  |
| **`db-username`**<br/>The username of the database user.<br/>**Named key:** `db-username-<datasource>`<br/>**CLI:** `--db-username`<br/>**Env:** `KC_DB_USERNAME` | _String_ |  |
