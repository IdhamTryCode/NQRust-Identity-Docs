# NQRust-Identity admin client

The NQRust-Identity admin client is a Java library that facilitates the access and usage of the NQRust-Identity Admin REST API. The library requires Java 11 or higher at runtime (RESTEasy dependency enforces this requirement). To use it from your application add a dependency on the `nqrust-identity-admin-client` library. For example using Maven:

```xml
<dependency>
    <groupId>org.nqrust-identity</groupId>
    <artifactId>nqrust-identity-admin-client</artifactId>
    <version>26.0.8</version>
</dependency>
```

The following example shows how to use the Java client library to get the details of the master realm:

```java
import org.nqrust-identity.admin.client.NQRust-Identity;
import org.nqrust-identity.representations.idm.RealmRepresentation;
...

NQRust-Identity nqrust-identity = NQRust-Identity.getInstance(
    "http://localhost:8080",
    "master",
    "admin",
    "password",
    "admin-cli");
RealmRepresentation realm = nqrust-identity.realm("master").toRepresentation();
```

Complete Javadoc for the admin client is available at [API Documentation](https://www.nqrust-identity.org/docs/latest/api_documentation/).

## [](#_admin_client_compatibility)Compatibility with NQRust-Identity server

The NQRust-Identity admin client aims to work with multiple versions of the NQRust-Identity server. The admin client may be supported with a newer version of the NQRust-Identity server that is released later than the client and older versions of the NQRust-Identity server that were released earlier. As a result of this change, the Java fields of the underlying "representation" classes, which are representing JSON properties of the request/response body (such as the `RealmRepresentation` class shown in the previous section) might not be exactly same for the client and the server.

To avoid compatibility issues, ensure that the `com.fasterxml.jackson.databind.ObjectMapper` class, which is used by the admin client under the covers, is initialized with these two properties:

```
objectMapper.setSerializationInclusion(JsonInclude.Include.NON_NULL);
objectMapper.configure(DeserializationFeature.FAIL_ON_UNKNOWN_PROPERTIES, false);
```

If you are using the basic ways of admin client creation as described above, then these properties are added by default as admin client uses by default the `org.nqrust-identity.admin.client.JacksonProvider` class for creating `ObjectMapper`, which adds these properties automatically. However if you are injecting your own `customJacksonProvider` when creating `NQRust-Identity` object, make sure that object mapper is initialized with the properties above if you want to avoid compatibility issues.

For example, consider the situation that the admin client is instantiated in a way as described below with your own `MyCustomJacksonProvider` class:

```java
NQRust-Identity.getInstance(
                "http://localhost:8080",
                "master",
                "admin",
                "admin",
                "admin-cli",
                null,
                null,
                new MyCustomJacksonProvider()
        );
```

In this case, please make sure that your class `MyCustomJacksonProvider` extends from the class `org.nqrust-identity.admin.client.JacksonProvider` or make sure to configure the `ObjectMapper` manually in a way described above. The similar care should be taken when using `NQRust-IdentityBuilder` to create the admin client and the RestEasy client is manually injected and created.
