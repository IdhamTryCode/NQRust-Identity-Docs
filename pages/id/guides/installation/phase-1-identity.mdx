# Fase 1: Instalasi Identity

import { Callout } from 'nextra/components'

Pada fase ini, Anda mengonfigurasi port service dan men-deploy container Identity dan Portal.

## Jalankan installer

Jalankan installer dari direktori tempat file konfigurasi akan disimpan:

```bash
./nqrust-portal-airgapped
```

Installer akan mendeteksi mode airgapped dan memuat Docker image yang dibundel:

```
Installer running in offline mode...
Loading bundled images, please wait...
```

## Pilih "Install Identity"

Gunakan tombol panah untuk menyorot **Install Identity**, lalu tekan **Enter** untuk mengonfirmasi.

![Menu Home dengan Install Identity tersorot](/images/installation/phase-1-1.png)

## Pengaturan server Identity

Hostname server terdeteksi secara otomatis; Anda hanya perlu menetapkan port.

### Pengaturan port server

| Field | Deskripsi | Contoh |
| --- | --- | --- |
| **Identity Port** | Port HTTPS eksternal untuk Identity Admin Console | `8082` (default) |
| **Portal Port** | Port HTTPS eksternal untuk Portal | `8083` (default) |

### Navigasi

- **Tab** atau **panah Atas/Bawah** — berpindah antar field.
- **Enter** — mengedit field yang terpilih.
- **Esc** — berhenti mengedit field saat ini.

![Form Identity terisi](/images/installation/phase-1-2.png)

<Callout type="info">
  Kedua port harus berada di rentang `1024`–`65535` dan tidak boleh sama. Pastikan tidak ada service lain di server yang menggunakan port tersebut.
</Callout>

Setelah nilai valid, arahkan ke tombol **Install** dan tekan **Enter** untuk memulai instalasi.

## Instalasi sedang berjalan

Installer menghasilkan file konfigurasi, menyiapkan bundle Docker Compose, dan menjalankan service. Progress bar dan log realtime ditampilkan selama setiap service dijalankan.

![Progress instalasi](/images/installation/phase-1-3.png)

Startup pertama dapat memakan waktu 1–3 menit selama setiap service menginisialisasi database dan menjalankan health check.

## Instalasi selesai

Setelah seluruh service berjalan, layar sukses akan menampilkan Identity admin URL.

![Sukses instalasi Identity](/images/installation/phase-1-4.png)

<Callout type="warning">
  Portal belum sepenuhnya berfungsi. Selesaikan **[Fase 2: Konfigurasi Portal](/id/guides/installation/phase-2-portal)** untuk menghubungkannya ke OAuth client di Identity.
</Callout>

## Langkah berikutnya

Tekan **i** pada layar sukses untuk lanjut ke Fase 2, atau tekan **q** untuk keluar dari installer dan melanjutkan nanti.

Lanjut ke [Fase 2: Konfigurasi Portal →](/id/guides/installation/phase-2-portal)
