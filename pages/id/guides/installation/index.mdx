# Ikhtisar Instalasi

import { Callout } from 'nextra/components'

NQRust-Identity Portal Installer adalah tool berbasis terminal yang men-deploy stack NQRust-Identity pada server Linux. Instalasi dilakukan dalam dua fase melalui text user interface yang terpandu.

## Yang akan terinstal

Installer men-deploy dua service sebagai Docker container:

- **Identity** — provider OIDC/OAuth2 untuk autentikasi dan otorisasi.
- **Portal** — aplikasi web untuk manajemen lisensi dan administrasi.

Kedua service dikonfigurasi dengan HTTPS secara default.

## Prasyarat

### Persyaratan sistem

- Server Linux (disarankan Ubuntu 24.04 LTS)
- Akses `sudo`
- 15–40 GB ruang disk kosong
- Hostname atau IP statis yang dapat dijangkau pengguna

### Persyaratan software

- **Docker Engine** terinstal dan berjalan
- **Docker Compose v2** (perintah `docker compose`)

<Callout type="info">
  Lihat [dokumentasi resmi Docker](https://docs.docker.com/engine/install/) untuk memasang Docker Engine dan Docker Compose.
</Callout>

### File installer

Installer beroperasi dalam **mode airgapped**. Semua Docker image yang dibutuhkan sudah dibundel ke dalam satu binary self-extracting, sehingga tidak diperlukan akses internet saat instalasi.

Dua file yang dibutuhkan:

| File | Deskripsi |
| --- | --- |
| `nqrust-portal-airgapped` | Binary installer (~534 MB) |
| `nqrust-portal-airgapped.sha256` | Checksum SHA256 |

<Callout type="warning">
  File-file ini tidak tersedia secara publik. Hubungi tim NQRust untuk memperoleh paket installer airgapped.
</Callout>

## Verifikasi installer

Letakkan kedua file di direktori yang sama pada server, lalu verifikasi checksum-nya:

```bash
sha256sum -c nqrust-portal-airgapped.sha256
```

Output yang diharapkan:

```
nqrust-portal-airgapped: OK
```

<Callout type="warning">
  Jika checksum tidak cocok, jangan lanjutkan. Hubungi tim NQRust untuk mendapatkan salinan installer yang baru.
</Callout>

## Jadikan binary dapat dieksekusi

```bash
chmod +x nqrust-portal-airgapped
```

## Jalankan installer

Jalankan installer dari direktori tempat file konfigurasi (`.env`, `docker-compose.yaml`) akan dibuat:

```bash
./nqrust-portal-airgapped
```

Pada peluncuran pertama, installer memuat Docker image yang dibundel ke dalam Docker daemon lokal. Proses ini dapat memakan waktu beberapa menit.
