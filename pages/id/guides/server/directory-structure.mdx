# Struktur Direktori

import { Callout } from 'nextra/components'

## Lokasi Instalasi

Jika Anda menginstal dari file zip, maka secara default akan ada direktori root instalasi `nqrust-identity-26.6.0`, yang dapat dibuat dimanapun Anda suka dalam sistem file Anda.

`/opt/nqrust-identity` adalah lokasi root instalasi untuk server dalam semua penggunaan kontainer yang ditunjukkan untuk NQRust-Identity, termasuk Menjalankan NQRust-Identity dalam kontainer, Docker, Podman, Kubernetes, dan OpenShift.

<Callout type="info">
  Dalam dokumentasi selanjutnya, jalur relatif dipahami sebagai relatif terhadap root instalasi - misalnya, conf/file.xml berarti &lt;install root&gt;/conf/file.xml
</Callout>

## Struktur Direktori

Di bawah root instalasi NQRust-Identity terdapat beberapa folder:

- **bin/** - berisi semua script shell untuk server, termasuk `kc.sh|bat`, `kcadm.sh|bat`, dan `kcreg.sh|bat`

  - **client/** - digunakan secara internal
- **conf/** - direktori yang digunakan untuk file konfigurasi, termasuk `nqrust-identity.conf` - lihat [Mengonfigurasi NQRust-Identity](/en/guides/server/configuration). Banyak opsi untuk menentukan file konfigurasi mengharapkan jalur relatif terhadap direktori ini.

  - **truststores/** - jalur default yang digunakan oleh opsi `truststore-paths` - lihat Mengonfigurasi sertifikat terpercaya
- **data/** - direktori untuk server menyimpan informasi runtime, seperti log transaksi

  - **logs/** - direktori default untuk logging file - lihat [Mengonfigurasi logging](/en/guides/server/logging)
- **lib/** - digunakan secara internal
- **providers/** - direktori untuk dependensi yang disediakan pengguna - lihat [Mengonfigurasi providers](/en/guides/server/configuration-provider) untuk memperluas server dan [Mengonfigurasi database](/en/guides/server/db) sebagai contoh menambahkan driver JDBC.
- **themes/** - direktori untuk penyesuaian pada Konsol Admin - lihat Mengembangkan Themes
