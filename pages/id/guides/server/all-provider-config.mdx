# Konfigurasi Semua Penyedia

## [](#_sesi_autentikasi)sesi-autentikasi

### [](#_infinispan)infinispan

  

Jenis atau Nilai

Default

`spi-authentication-sessions--infinispan--auth-sessions-limit`

Jumlah maksimum sesi autentikasi bersamaan per RootAuthenticationSession.

**CLI:** `--spi-authentication-sessions--infinispan--auth-sessions-limit`  
**Env:** `KC_SPI_AUTHENTICATION_SESSIONS__INFINISPAN__AUTH_SESSIONS_LIMIT`

_integer_

`300`

### [](#_remote)remote

  

Jenis atau Nilai

Default

`spi-authentication-sessions--remote--auth-sessions-limit`

Jumlah maksimum sesi autentikasi bersamaan per RootAuthenticationSession.

**CLI:** `--spi-authentication-sessions--remote--auth-sessions-limit`  
**Env:** `KC_SPI_AUTHENTICATION_SESSIONS__REMOTE__AUTH_SESSIONS_LIMIT`

_integer_

`300`

`spi-authentication-sessions--remote--max-retries`

Jumlah maksimum pengulangan jika terjadi kesalahan.

Nilai nol atau kurang dari nol menonaktifkan pengulangan.

**CLI:** `--spi-authentication-sessions--remote--max-retries`  
**Env:** `KC_SPI_AUTHENTICATION_SESSIONS__REMOTE__MAX_RETRIES`

_integer_

`10`

`spi-authentication-sessions--remote--retry-base-time`

Waktu dasar penundaan kembali dalam milidetik.

**CLI:** `--spi-authentication-sessions--remote--retry-base-time`  
**Env:** `KC_SPI_AUTHENTICATION_SESSIONS__REMOTE__RETRY_BASE_TIME`

_integer_

`10`

Default

`spi-cache-embedded--default--action-tokens-owners`

Menyetel jumlah pemilik untuk cache terdistribusi actionTokens.

Ini mendefinisikan jumlah salinan data Anda di dalam kluster.

**CLI:** `--spi-cache-embedded--default--action-tokens-owners`

**CLI:** `--spi-cache-embedded--default--authentication-sessions-owners`  
**Env:** `KC_SPI_CACHE_EMBEDDED__DEFAULT__AUTHENTICATION_SESSIONS_OWNERS`

_Angka_integer_

`spi-cache-embedded--default--authorization-max-count`

Jumlah maksimum entri yang dapat disimpan dalam memori oleh cache otorisasi.

**Env:** `KC_SPI_CACHE_EMBEDDED__DEFAULT__AUTHORIZATION_MAX_COUNT`

_Angka_integer_

`spi-cache-embedded--default--client-sessions-max-count`
