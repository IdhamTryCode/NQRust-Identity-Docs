# Menginisialisasi dan memulihkan akun admin

import { Callout } from 'nextra/components'

## Akun admin sementara

Akun admin pengguna atau layanan yang dibuat menggunakan salah satu metode yang dijelaskan di bawah ini adalah **sementara**. Ini berarti akun tersebut hanya seharusnya ada untuk durasi yang diperlukan untuk melakukan operasi yang diperlukan untuk mendapatkan akses admin yang lebih permanen dan lebih aman. Setelah itu, akun tersebut perlu dihapus secara manual. Beberapa elemen UI/UX, seperti spanduk peringatan Konsol Administrasi, label, dan pesan log, akan menunjukkan kepada administrator NQRust-Identity bahwa akun ini adalah sementara.

## Menginisialisasi akun admin sementara saat startup NQRust-Identity

Perintah `start` dan `start-dev` NQRust-Identity mendukung opsi untuk menginisialisasi akun admin pengguna dan akun layanan admin sementara. Opsi ini adalah opsi konfigurasi standar, jadi dapat ditentukan di salah satu [sumber konfigurasi](/en/guides/server/configuration#_configuring_sources_for_nqrust-identity) seperti variabel lingkungan atau parameter CLI. Sebagai contoh, contoh berikut menunjukkan cara menggunakan perintah `start` dan `start-dev` dengan parameter CLI untuk menginisialisasi akun admin pengguna sementara dan akun layanan admin, masing-masing:

```bash
bin/kc.[sh|bat] start --bootstrap-admin-username tmpadm --bootstrap-admin-password pass
```

```bash
bin/kc.[sh|bat] start-dev --bootstrap-admin-client-id tmpadm --bootstrap-admin-client-secret secret
```

Nilai username atau ID klien dapat diabaikan; lihat bagian [Nilai Default](#_default_values) di bawah untuk informasi lebih lanjut.

Tujuan opsi ini hanya untuk menginisialisasi akun admin sementara. Akun ini akan dibuat hanya saat startup awal server NQRust-Identity saat realm master belum ada. Akun akan selalu dibuat di realm master. Untuk memulihkan akses admin yang hilang, gunakan perintah khusus yang dijelaskan di bagian di bawah.

## Menginisialisasi admin pengguna atau akun layanan menggunakan perintah khusus

Perintah `bootstrap-admin` dapat dieksekusi bahkan sebelum startup pertama NQRust-Identity. Perlu diingat bahwa semua node NQRust-Identity harus dihentikan sebelum menggunakan perintah ini. Eksekusi perintah ini akan memicu pembuatan realm master awal, dan sebagai akibatnya, opsi startup untuk menginisialisasi pengguna admin dan akun layanan akan diabaikan saat server dimulai untuk pertama kali.

Selain itu, sangat disarankan untuk menggunakan perintah khusus dengan opsi yang sama dengan server NQRust-Identity (mis., opsi `db`).

Jika Anda telah membangun versi yang dioptimalkan NQRust-Identity dengan perintah `build` sebagai yang dijelaskan dalam [Konfigurasi NQRust-Identity](/en/guides/server/configuration), gunakan opsi baris perintah `--optimized` agar NQRust-Identity melewati pemeriksaan build untuk waktu startup yang lebih cepat.
Saat melakukan ini, hapus opsi waktu build dari baris perintah dan simpan hanya opsi runtime.

<Callout type="info">
  jika Anda tidak menggunakan --optimized, perhatikan bahwa perintah bootstrap-admin mungkin secara implisit membuat atau memperbarui build yang dioptimalkan untuk Anda - jika Anda menjalankan perintah dari mesin yang sama dengan instance server, ini mungkin mempengaruhi startup berikutnya server Anda.
</Callout>

### Membuat admin pengguna

Untuk membuat admin pengguna sementara, eksekusi perintah berikut:

```bash
bin/kc.[sh|bat] bootstrap-admin user
```

Jika tidak ada parameter lain yang ditentukan dan/atau tidak ada variabel lingkungan yang sesuai yang diatur, pengguna akan diminta untuk memasukkan informasi yang diperlukan. Nilai username dapat diabaikan untuk menggunakan nilai default. Untuk informasi lebih lanjut, lihat bagian [Nilai Default](
