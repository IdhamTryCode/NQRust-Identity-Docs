# All configuration

## Cache

| Opsi | _Tipe_ atau Nilai | Default |
| --- | --- | --- |
| **`cache`**<br/>Menentukan mekanisme cache untuk ketersediaan tinggi.<br/>Pada mode produksi secara default, cache `ispn` digunakan untuk membuat kluster antara beberapa node server. Pada mode pengembangan secara default, cache `local` menonaktifkan kluster dan ditujukan untuk tujuan pengembangan dan pengujian.<br/>**CLI:** `--cache`<br/>**Env:** `KC_CACHE` | `ispn`, `local` |  |
| **`cache-config-file`**<br/>Menentukan file dari mana konfigurasi cache harus diambil.<br/>File konfigurasi relatif terhadap direktori `conf/`.<br/>**CLI:** `--cache-config-file`<br/>**Env:** `KC_CACHE_CONFIG_FILE` | _File_ |  |
| **`cache-config-mutate`**<br/>Menentukan apakah diizinkan perubahan pada konfigurasi cache default.<br/>Hanya disarankan untuk kasus penggunaan lanjutan di mana konfigurasi cache default terbukti menjadi masalah. Cara yang didukung untuk mengubah konfigurasi cache default hanya melalui opsi `cache-…​` lainnya.<br/>**CLI:** `--cache-config-mutate`<br/>**Env:** `KC_CACHE_CONFIG_MUTATE` | `true`, `false` | `false` |
| **`cache-embedded-authorization-max-count`**<br/>Jumlah maksimal entri yang dapat disimpan dalam memori oleh cache otorisasi.<br/>**CLI:** `--cache-embedded-authorization-max-count`<br/>**Env:** `KC_CACHE_EMBEDDED_AUTHORIZATION_MAX_COUNT` | _Integer_ |  |
| **`cache-embedded-client-sessions-max-count`**<br/>Jumlah maksimal entri yang dapat disimpan dalam memori oleh cache clientSessions.<br/>**CLI:** `--cache-embedded-client-sessions-max-count`<br/>**Env:** `KC_CACHE_EMBEDDED_CLIENT_SESSIONS_MAX_COUNT` | _Integer_ |  |
| **`cache-embedded-crl-max-count`**<br/>Jumlah maksimal entri yang dapat disimpan dalam memori oleh cache crl.<br/>**CLI:** `--cache-embedded-crl-max-count`<br/>**Env:** `KC_CACHE_EMBEDDED_CRL_MAX_COUNT` | _Integer_ |  |
| **`cache-embedded-keys-max-count`**<br/>Jumlah maksimal entri yang dapat disimpan dalam memori oleh cache keys.<br/>**CLI:** `--cache-embedded-keys-max-count`<br/>**Env:** `KC_CACHE_EMBEDDED_KEYS_MAX_COUNT` | _Integer_ |  |
| **`cache-embedded-mtls-enabled`**<br/>Mengenkripsi komunikasi jaringan antara server NQRust-Identity.<br/>Jika tidak ada parameter tambahan tentang keystore dan truststore yang diberikan, pasangan kunci sementara dan sertifikat dibuat dan diputar secara otomatis, yang disarankan untuk pengaturan standar.<br/>**CLI:** `--cache-embedded-mtls-enabled`<br/>**Env:** `KC_CACHE_EMBEDDED_MTLS_ENABLED` | `true`, `false` | `true` |
| **`cache-embedded-mtls-key-store-file`**<br/>Jalur file Keystore.<br/>Keystore harus berisi sertifikat yang akan digunakan oleh protokol TLS. Secara default, mencari `cache-mtls-keystore.p12` di bawah direktori conf/.<br/>**CLI:** `--cache-embedded-mtls-key-store-file`<br/>**Env:** `KC_CACHE_EMBEDDED_MTLS_KEY_STORE_FILE` | _String_ |  |
| **`cache-embedded-mtls-key-store-password`**<br/>Kata sandi untuk mengakses Keystore.<br/>**CLI:** `--cache-embedded-mtls-key-store-password`<br/>**Env:** `KC_CACHE_EMBEDDED_MTLS_KEY_STORE_PASSWORD` | _String_ |  |
| **`cache-embedded-mtls-rotation-interval-days`**<br/>Jangka waktu putaran sertifikat JGroups MTLS otomatis dalam hari.<br/>**CLI:** `--cache-embedded-mtls-rotation-interval-days`<br/>**Env:** `KC_CACHE_EMBEDDED_MTLS_ROTATION_INTERVAL_DAYS` | _Integer_ | `30` |
| **`cache-embedded-mtls-trust-store-file`**<br/>Jalur file Truststore.<br/>Harus berisi sertifikat terpercaya atau Otoritas Sertifikat yang menandatangani sertifikat. Secara default, mencari `cache-mtls-truststore.p12` di bawah direktori conf/.<br/>**CLI:** `--cache-embedded-mtls-trust-store-file`<br/>**Env:** `KC_CACHE_EMBEDDED_MTLS_TRUST_STORE_FILE` | _String_ |  |
| **`cache-embedded-mtls-trust-store-password`**<br/>Kata sandi untuk mengakses Truststore.<br/>**CLI:** `--cache-embedded-mtls-trust-store-password`<br/>**Env:** `KC_CACHE_EMBEDDED_MTLS_TRUST_STORE_PASSWORD` | _String_ |  |
| **`cache-embedded-network-bind-address`**<br/>Alamat IP yang digunakan oleh transport kluster.<br/>Secara default, digunakan SITE_LOCAL.<br/>**CLI:** `--cache-embedded-network-bind-address`<br/>**Env:** `KC_CACHE_EMBEDDED_NETWORK_BIND_ADDRESS` | _String_ |  |
| **`cache-embedded-network-bind-port`**<br/>Port yang akan terikat oleh transport kluster.<br/>Secara default, port 7800 digunakan.<br/>**CLI:** `--cache-embedded-network-bind-port`<br/>**Env:** `KC_CACHE_EMBEDDED_NETWORK_BIND_PORT` | _Integer_ |  |
| **`cache-embedded-network-external-address`**<br/>Alamat IP yang harus digunakan oleh instance lain di kluster untuk menghubungi node ini.<br/>Hanya diatur jika berbeda dengan cache-embedded-network-bind-address, misalnya ketika instance ini di belakang firewall.<br/>**CLI:** `--cache-embedded-network-external-address`<br/>**Env:** `KC_CACHE_EMBEDDED_NETWORK_EXTERNAL_ADDRESS` | _String_ |  |
| **`cache-embedded-network-external-port`**<br/>Port yang harus digunakan oleh instance lain di kluster untuk menghubungi node ini.<br/>Hanya diatur jika berbeda dengan cache-embedded-network-bind-port, misalnya ketika instance ini di belakang firewall<br/>**CLI:** `--cache-embedded-network-external-port`<br/>**Env:** `KC_CACHE_EMBEDDED_NETWORK_EXTERNAL_PORT` | _Integer_ |  |
| **`cache-embedded-offline-client-sessions-max-count`**<br/>Jumlah maksimal entri yang dapat disimpan dalam memori oleh cache offlineClientSessions.<br/>**CLI:** `--cache-embedded-offline-client-sessions-max-count`<br/>**Env:** `KC_CACHE_EMBEDDED_OFFLINE_CLIENT_SESSIONS_MAX_COUNT` | _Integer_ |  |
| **`cache-embedded-offline-sessions-max-count`**<br/>Jumlah maksimal entri yang dapat disimpan dalam memori oleh cache offlineSessions.<br/>**CLI:** `--cache-embedded-offline-sessions-max-count`<br/>**Env:** `KC_CACHE_EMBEDDED_OFFLINE_SESSIONS_MAX_COUNT` | _Integer_ |  |
| **`cache-embedded-realms-max-count`**<br/>Jumlah maksimal entri yang dapat disimpan dalam memori oleh cache realms.<br/>**CLI:** `--cache-embedded-realms-max-count`<br/>**Env:** `KC_CACHE_EMBEDDED_REALMS_MAX_COUNT` | _Integer_ |  |
| **`cache-embedded-sessions-max-count`**<br/>Jumlah maksimal entri yang dapat disimpan dalam memori oleh cache sessions.<br/>**CLI:** `--cache-embedded-sessions-max-count`<br/>**Env:** `KC_CACHE_EMBEDDED_SESSIONS_MAX_COUNT` | _Integer_ |  |
| **`cache-embedded-users-max-count`**<br/>Jumlah maksimal entri yang dapat disimpan dalam memori oleh cache users.<br/>**CLI:** `--cache-embedded-users-max-count`<br/>**Env:** `KC_CACHE_EMBEDDED_USERS_MAX_COUNT` | _Integer_ |  |
| **`cache-metrics-histograms-enabled`**<br/>Aktifkan histogram untuk metrik cache yang diembed.<br/>**CLI:** `--cache-metrics-histograms-enabled`<br/>**Env:** `KC_CACHE_METRICS_HISTOGRAMS_ENABLED` | `true`, `false` | `false` |
| **`cache-remote-backup-sites`**<br/>Mengonfigurasi daftar nama situs cadangan tempat kluster Infinispan eksternal menyandorkan data NQRust-Identity.<br/>**CLI:** `--cache-remote-backup-sites`<br/>**Env:** `KC_CACHE_REMOTE_BACKUP_SITES` | _Daftar_ |  |
| **`cache-remote-host`**<br/>Nama host dari kluster Infinispan eksternal.<br/>Tersedia hanya ketika fitur `multi-site` atau `clusterless` diatur.<br/>**CLI:** `--cache-remote-host`<br/>**Env:** `KC_CACHE_REMOTE_HOST` | _String_ |  |
| **`cache-remote-password`**<br/>Kata sandi untuk otentikasi ke kluster Infinispan eksternal.<br/>Opsional jika terhubung ke kluster Infinispan eksternal yang tidak aman. Jika opsi ini ditentukan, `cache-remote-username` juga diperlukan.<br/>**CLI:** `--cache-remote-password`<br/>**Env:** `KC_CACHE_REMOTE_PASSWORD` | _String_ |  |
| **`cache-remote-port`**<br/>Port dari kluster Infinispan eksternal.<br/>**CLI:** `--cache-remote-port`<br/>**Env:** `KC_CACHE_REMOTE_PORT` | _Integer_ | `11222` |
| **`cache-remote-tls-enabled`**<br/>Aktifkan dukungan TLS untuk berkomunikasi dengan server Infinispan eksternal yang terjamin.<br/>Disarankan untuk diaktifkan dalam produksi.<br/>**CLI:** `--cache-remote-tls-enabled`<br/>**Env:** `KC_CACHE_REMOTE_TLS_ENABLED` | `true`, `false` | `true` |
| **`cache-remote-username`**<br/>Nama pengguna untuk otentikasi ke kluster Infinispan eksternal.<br/>Opsional jika terhubung ke kluster Infinispan eksternal yang tidak aman. Jika opsi ini ditentukan, `cache-remote-password` juga diperlukan.<br/>**CLI:** `--cache-remote-username`<br/>**Env:** `KC_CACHE_REMOTE_USERNAME` | _String_ |  |
| **`cache-stack`**<br/>Menentukan tumpukan default untuk komunikasi kluster dan penemuan node.<br/>Secara default, `jdbc-ping` jika tidak diatur.<br/>**CLI:** `--cache-stack`<br/>**Env:** `KC_CACHE_STACK` | `jdbc-ping`, `kubernetes` (usang), `jdbc-ping-udp` (usang), `tcp` (usang), `udp` (usang), `ec2` (usang), `azure` (usang), `google` (usang), atau apapun |  |

## Database

| Pilihan | _Tipe_ atau Nilai | Default |
| --- | --- | --- |
| **`db`**<br/>Penyedia database.<br/>Dalam mode produksi, nilai default `dev-file` dianggap usang, Anda harus secara eksplisit menentukan db.<br/>**Kunci bernama:** `db-kind-<datasource>`<br/>**CLI:** `--db`<br/>**Env:** `KC_DB` | `dev-file`, `dev-mem`, `mariadb`, `mssql`, `mysql`, `oracle`, `postgres`, `tidb` | `dev-file` |
| **`db-connect-timeout`**<br/>Mengatur waktu timeout koneksi driver JDBC dan waktu login.<br/>Mungkin merupakan nilai durasi ISO 8601, bilangan bulat detik, atau bilangan bulat diikuti salah satu [ms, h, m, s, d].<br/>**CLI:** `--db-connect-timeout`<br/>**Env:** `KC_DB_CONNECT_TIMEOUT` | _String_ | `10s` |
| **`db-debug-jpql`**<br/>Menambahkan informasi JPQL sebagai komentar pada pernyataan SQL untuk debug generasi pernyataan SQL JPA.<br/>**Kunci bernama:** `db-debug-jpql-<datasource>`<br/>**CLI:** `--db-debug-jpql`<br/>**Env:** `KC_DB_DEBUG_JPQL` | `true`, `false` | `false` |
| **`db-driver`**<br/>Nama kelas lengkap dari driver JDBC.<br/>Jika tidak diatur, driver default akan ditetapkan sesuai dengan database yang dipilih.<br/>**Kunci bernama:** `db-driver-<datasource>`<br/>**CLI:** `--db-driver`<br/>**Env:** `KC_DB_DRIVER` | _String_ |  |
| **`db-log-slow-queries-threshold`**<br/>Log pernyataan SQL yang lebih lambat dari ambang batas yang dikonfigurasi dengan logger org.<br/>hibernate.SQL_SLOW dan log-level info.<br/>**Kunci bernama:** `db-log-slow-queries-threshold-<datasource>`<br/>**CLI:** `--db-log-slow-queries-threshold`<br/>**Env:** `KC_DB_LOG_SLOW_QUERIES_THRESHOLD` | _Integer_ | `10000` |
| **`db-password`**<br/>Kata sandi pengguna database.<br/>**Kunci bernama:** `db-password-<datasource>`<br/>**CLI:** `--db-password`<br/>**Env:** `KC_DB_PASSWORD` | _String_ |  |
| **`db-pool-initial-size`**<br/>Ukuran awal pool koneksi.<br/>**Kunci bernama:** `db-pool-initial-size-<datasource>`<br/>**CLI:** `--db-pool-initial-size`<br/>**Env:** `KC_DB_POOL_INITIAL_SIZE` | _Integer_ |  |
| **`db-pool-max-lifetime`**<br/>Waktu maksimum koneksi yang tetap dalam pool, setelah itu akan ditutup saat dikembalikan dan diganti sesuai kebutuhan.<br/>Mungkin merupakan nilai durasi ISO 8601, bilangan bulat detik, atau bilangan bulat diikuti salah satu [ms, h, m, s, d].<br/>**CLI:** `--db-pool-max-lifetime`<br/>**Env:** `KC_DB_POOL_MAX_LIFETIME` | _String_ |  |
| **`db-pool-max-size`**<br/>Ukuran maksimum pool koneksi.<br/>**Kunci bernama:** `db-pool-max-size-<datasource>`<br/>**CLI:** `--db-pool-max-size`<br/>**Env:** `KC_DB_POOL_MAX_SIZE` | _Integer_ | `100` |
| **`db-pool-min-size`**<br/>Ukuran minimal pool koneksi.<br/>**Kunci bernama:** `db-pool-min-size-<datasource>`<br/>**CLI:** `--db-pool-min-size`<br/>**Env:** `KC_DB_POOL_MIN_SIZE` | _Integer_ |  |
| **`db-schema`**<br/>Skema database yang akan digunakan.<br/>**Kunci bernama:** `db-schema-<datasource>`<br/>**CLI:** `--db-schema`<br/>**Env:** `KC_DB_SCHEMA` | _String_ |  |
| **`db-tls-mode`**<br/>Mengatur mode TLS untuk koneksi database.<br/>Jika dinonaktifkan, menggunakan nilai default driver. Ketika diatur ke verify-server, mengaktifkan enkripsi dan verifikasi identitas server. Dibutuhkan sertifikat server database atau sertifikat Otoritas Sertifikat (CA).<br/>**Kunci bernama:** `db-tls-mode-<datasource>`<br/>**CLI:** `--db-tls-mode`<br/>**Env:** `KC_DB_TLS_MODE` | `disabled`, `verify-server` | `disabled` |
| **`db-tls-trust-store-file`**<br/>Jalur ke file truststore yang berisi sertifikat server database atau sertifikat Otoritas Sertifikat (CA) yang digunakan untuk verifikasi identitas server database.<br/>**Kunci bernama:** `db-tls-trust-store-file-<datasource>`<br/>**CLI:** `--db-tls-trust-store-file`<br/>**Env:** `KC_DB_TLS_TRUST_STORE_FILE` | _File_ |  |
| **`db-tls-trust-store-password`**<br/>Kata sandi untuk mengakses file truststore yang ditentukan dalam db-tls-trust-store-file (jika diperlukan dan didukung oleh driver JDBC).<br/>**Kunci bernama:** `db-tls-trust-store-password-<datasource>`<br/>**CLI:** `--db-tls-trust-store-password`<br/>**Env:** `KC_DB_TLS_TRUST_STORE_PASSWORD` | _String_ |  |
| **`db-tls-trust-store-type`**<br/>Jenis file truststore.<br/>Nilai umum meliputi `JKS` (Java KeyStore) dan `PKCS12`. Jika tidak ditentukan, menggunakan nilai default driver.<br/>**Kunci bernama:** `db-tls-trust-store-type-<datasource>`<br/>**CLI:** `--db-tls-trust-store-type`<br/>**Env:** `KC_DB_TLS_TRUST_STORE_TYPE` | _String_ |  |
| **`db-url`**<br/>URL JDBC database lengkap.<br/>Jika tidak diberikan, URL default akan ditetapkan berdasarkan penyedia database yang dipilih. Misalnya, jika menggunakan `postgres`, URL JDBC default akan menjadi `jdbc:postgresql://localhost/keycloak`.<br/>**Kunci bernama:** `db-url-full-<datasource>`<br/>**CLI:** `--db-url`<br/>**Env:** `KC_DB_URL` | _String_ |  |
| **`db-url-database`**<br/>Mengatur nama database dari URL JDBC default penyedia yang dipilih.<br/>Jika opsi `db-url` diatur, opsi ini diabaikan.<br/>**Kunci bernama:** `db-url-database-<datasource>`<br/>**CLI:** `--db-url-database`<br/>**Env:** `KC_DB_URL_DATABASE` | _String_ |  |
| **`db-url-host`**<br/>Mengatur nama host dari URL JDBC default penyedia yang dipilih.<br/>Jika opsi `db-url` diatur, opsi ini diabaikan.<br/>**Kunci bernama:** `db-url-host-<datasource>`<br/>**CLI:** `--db-url-host`<br/>**Env:** `KC_DB_URL_HOST` | _String_ |  |
| **`db-url-port`**<br/>Mengatur port dari URL JDBC default penyedia yang dipilih.<br/>Jika opsi `db-url` diatur, opsi ini diabaikan.<br/>**Kunci bernama:** `db-url-port-<datasource>`<br/>**CLI:** `--db-url-port`<br/>**Env:** `KC_DB_URL_PORT` | _Integer_ |  |
| **`db-url-properties`**<br/>Mengatur properti dari URL JDBC default penyedia yang dipilih.<br/>Pastikan untuk mengatur properti sesuai dengan format yang diharapkan oleh penyedia database, serta menambahkan karakter yang tepat di awal nilai properti ini. Jika opsi `db-url` diatur, opsi ini diabaikan.<br/>**Kunci bernama:** `db-url-properties-<datasource>`<br/>**CLI:** `--db-url-properties`<br/>**Env:** `KC_DB_URL_PROPERTIES` | _String_ |  |
| **`db-username`**<br/>Nama pengguna database.<br/>**Kunci bernama:** `db-username-<datasource>`<br/>**CLI:** `--db-username`<br/>**Env:** `KC_DB_USERNAME` | _String_ |  |
