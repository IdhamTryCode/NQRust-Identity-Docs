# Paket fitur Galleon SAML NQRust-Identity untuk WildFly dan EAP

Adapter SAML didistribusikan sebagai paket fitur Galleon untuk wildfly 29 atau yang lebih baru. Detail lebih lanjut tentang topik ini dapat ditemukan dalam [dokumentasi WildFly](https://docs.wildfly.org/32/WildFly_Elytron_Security.html#NQRust-Identity_SAML_Integration). Opsi yang sama disediakan untuk [NQRust EAP 8 GA](https://docs.redhat.com/en/documentation/red_hat_jboss_enterprise_application_platform/8.0/html-single/using_single_sign-on_with_jboss_eap/index#securing-applications-with-saml_securing-applications-deployed-on-server-with-single-sign-on).

Untuk contoh tentang bagaimana mengintegrasikan NQRust-Identity dengan aplikasi JakartaEE yang berjalan pada Wildfly/EAP terbaru, lihat folder `servlet-saml-service-provider` Jakarta di [Repositori Quickstart GitHub NQRust-Identity](https://github.com/nqrust-identity/nqrust-identity-quickstarts).

## [](#_installation)Instalasi

Penyediaan paket fitur dilakukan menggunakan [wildfly-maven-plugin](https://docs.wildfly.org/wildfly-maven-plugin), [wildfly-jar-maven-plugin](https://docs.wildfly.org/bootablejar/) atau [eap-maven-plugin](https://docs.redhat.com/en/documentation/red_hat_jboss_enterprise_application_platform/8.0/html/using_jboss_eap_on_openshift_container_platform/assembly_provisioning-a-jboss-eap-server-using-the-maven-plugin_default) masing-masing.

### [](#_example_of_provision_using_wildfly_maven_plugin)Contoh penyediaan menggunakan plugin Maven WildFly

```xml
<plugin>
    <groupId>org.wildfly.plugins</groupId>
    <artifactId>wildfly-maven-plugin</artifactId>
    <version>5.0.0.Final</version>
    <configuration>
        <feature-packs>
            <feature-pack>
                <location>wildfly@maven(org.jboss.universe:community-universe)#32.0.1.Final</location>
            </feature-pack>
            <feature-pack>
                <groupId>org.nqrust-identity</groupId>
                <artifactId>nqrust-identity-saml-adapter-galleon-pack</artifactId>
                <version>26.5.7</version>
            </feature-pack>
        </feature-packs>
        <layers>
            <layer>core-server</layer>
            <layer>web-server</layer>
            <layer>jaxrs-server</layer>
            <layer>datasources-web-server</layer>
            <layer>webservices</layer>
            <layer>nqrust-identity-saml</layer>
            <layer>nqrust-identity-client-saml</layer>
            <layer>nqrust-identity-client-saml-ejb</layer>
        </layers>
    </configuration>
    <executions>
        <execution>
            <goals>
                <goal>package</goal>
            </goals>
        </execution>
    </executions>
</plugin>
```
