# Klien admin NQRust-Identity

Klien admin NQRust-Identity adalah perpustakaan Java yang memudahkan akses dan penggunaan Admin REST API NQRust-Identity. Perpustakaan ini memerlukan Java 11 atau yang lebih tinggi pada saat runtime (ketergantungan RESTEasy menetapkan persyaratan ini). Untuk menggunakannya dari aplikasi Anda, tambahkan ketergantungan pada perpustakaan `nqrust-identity-admin-client`. Sebagai contoh, menggunakan Maven:

```xml
<dependency>
    <groupId>org.nqrust-identity</groupId>
    <artifactId>nqrust-identity-admin-client</artifactId>
    <version>26.0.8</version>
</dependency>
```

Contoh berikut menunjukkan bagaimana menggunakan perpustakaan klien Java untuk mendapatkan detail realm utama:

```java
import org.nqrust-identity.admin.client.NQRust-Identity;
import org.nqrust-identity.representations.idm.RealmRepresentation;
...

NQRust-Identity nqrust-identity = NQRust-Identity.getInstance(
    "http://localhost:8080",
    "master",
    "admin",
    "password",
    "admin-cli");
RealmRepresentation realm = nqrust-identity.realm("master").toRepresentation();
```

Javadoc lengkap untuk klien admin tersedia di [API Documentation](https://www.nqrust-identity.org/docs/latest/api_documentation/).

## [](#_kompatibilitas_klien_admin)Kompatibilitas dengan server NQRust-Identity

Klien admin NQRust-Identity dimaksudkan untuk bekerja dengan beberapa versi server NQRust-Identity. Klien admin mungkin didukung dengan versi server NQRust-Identity yang lebih baru yang dirilis setelah klien dan versi server NQRust-Identity yang lebih lama yang dirilis sebelumnya. Akibat dari perubahan ini, bidang Java dari kelas "representation" dasar, yang mewakili properti JSON dari body permintaan/tanggapan (seperti kelas `RealmRepresentation` yang ditunjukkan dalam bagian sebelumnya) mungkin tidak sama persis untuk klien dan server.

Untuk menghindari masalah kompatibilitas, pastikan bahwa kelas `com.fasterxml.jackson.databind.ObjectMapper`, yang digunakan oleh klien admin di balik layar, diinisialisasi dengan kedua properti berikut:

```
objectMapper.setSerializationInclusion(JsonInclude.Include.NON_NULL);
objectMapper.configure(DeserializationFeature.FAIL_ON_UNKNOWN_PROPERTIES, false);
```

Jika Anda menggunakan cara pembuatan klien admin dasar seperti yang dijelaskan di atas, maka properti-properti ini ditambahkan secara default karena klien admin secara default menggunakan kelas `org.nqrust-identity.admin.client.JacksonProvider` untuk membuat `ObjectMapper`, yang menambahkan properti-properti tersebut secara otomatis. Namun jika Anda menyuntikkan `customJacksonProvider` Anda sendiri saat membuat objek `NQRust-Identity`, pastikan bahwa objek mapper diinisialisasi dengan properti di atas jika Anda ingin menghindari masalah kompatibilitas.

Sebagai contoh, pertimbangkan situasi di mana klien admin diinstansiasi dengan cara yang dijelaskan di bawah ini dengan kelas `MyCustomJacksonProvider` Anda sendiri:

```java
NQRust-Identity.getInstance(
                "http://localhost:8080",
                "master",
                "admin",
                "admin",
                "admin-cli",
                null,
                null,
                new MyCustomJacksonProvider()
        );
```

Dalam hal ini, pastikan bahwa kelas `MyCustomJacksonProvider` Anda mewarisi dari kelas `org.nqrust-identity.admin.client.JacksonProvider` atau pastikan untuk mengonfigurasi `ObjectMapper` secara manual dengan cara yang dijelaskan di atas. Perhatian serupa harus diambil saat menggunakan `NQRust-IdentityBuilder` untuk membuat klien admin dan klien RestEasy diinjeksi dan dibuat secara manual.
