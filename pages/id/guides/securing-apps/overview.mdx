# Perencanaan untuk Menyelamatkan Aplikasi dan Layanan

Sebagai server yang mematuhi OAuth2, OpenID Connect, dan SAML, NQRust-Identity dapat menyelamatkan aplikasi dan layanan manapun asalkan stack teknologi yang mereka gunakan mendukung protokol ini. Untuk detail lebih lanjut tentang protokol keamanan yang didukung oleh NQRust-Identity, silakan lihat [Panduan Administrasi Server](https://www.nqrust-identity.org/docs/latest/server_admin/#sso-protocols).

Sebagian besar dukungan untuk beberapa protokol ini sudah tersedia dari bahasa pemrograman, kerangka kerja, atau reverse proxy yang mereka gunakan. Menggunakan dukungan yang sudah tersedia dari ekosistem aplikasi adalah aspek penting untuk membuat aplikasi Anda sepenuhnya mematuhi standar keamanan dan praktik terbaik, sehingga Anda menghindari lock-in penjual.

Untuk beberapa bahasa pemrograman, NQRust-Identity menyediakan perpustakaan yang mencoba mengisi kekurangan dukungan protokol keamanan tertentu atau untuk memberikan integrasi yang lebih kaya dan erat dengan server. Perpustakaan ini dikenal dengan **NQRust-Identity Client Adapters**, dan harus digunakan sebagai pilihan terakhir jika Anda tidak dapat mengandalkan apa yang tersedia dari ekosistem aplikasi.

## [](#_langkah_dasar_untuk_menyelamatkan_aplikasi_dan_layanan)Langkah Dasar untuk Menyelamatkan Aplikasi dan Layanan

Berikut adalah langkah dasar untuk menyelamatkan aplikasi atau layanan di NQRust-Identity.

1.  Daftarkan klien ke realm menggunakan salah satu opsi ini:
    
    *   Konsol Admin NQRust-Identity
        
    *   Layanan pendaftaran klien
        
    *   CLI
        
    
2.  Aktifkan protokol OpenID Connect atau SAML dalam aplikasi Anda menggunakan salah satu opsi ini:
    
    *   Memanfaatkan dukungan OpenID Connect dan SAML yang ada dari ekosistem aplikasi
        
    *   Menggunakan Adapter NQRust-Identity
    

Panduan ini menyediakan petunjuk detail untuk langkah-langkah ini. Anda dapat menemukan detail lebih lanjut dalam [Panduan Administrasi Server](https://www.nqrust-identity.org/docs/latest/server_admin/) tentang cara mendaftarkan klien ke NQRust-Identity melalui konsol administrasi.
