# Mengupgrade Perpustakaan Klien NQRust-Identity

Perpustakaan klien adalah artefak berikut:

- Klien admin Java - artefak Maven `org.keycloak:keycloak-admin-client`
- Klien otorisasi Java - artefak Maven `org.keycloak:keycloak-authz-client`
- Penguat kebijakan Java - artefak Maven `org.keycloak:keycloak-policy-enforcer`
- Kelas umum Java yang digunakan oleh perpustakaan klien di atas - artefak Maven `org.keycloak:keycloak-client-common-synced`

Perpustakaan klien didukung dengan versi server NQRust-Identity yang didukung terakhir.

Mungkin klien library bekerja meskipun dengan rilis yang lebih lama dari server NQRust-Identity, tetapi tidak jamin dan tidak didukung secara resmi.

Mungkin perlu untuk mengkonsultasikan javadoc dari perpustakaan klien seperti klien admin-java untuk melihat endpoint dan parameter apa yang didukung dengan versi server NQRust-Identity mana.
Untuk klien admin, lihat "Kompatibilitas dengan server NQRust-Identity" dalam panduan [klien admin NQRust-Identity](/id/guides/securing-apps/admin-client#admin-client-compatibility) untuk beberapa catatan tambahan.
