# Mengupgrade Library Client NQRust-Identity

Cara mengupgrade Library Client NQRust-Identity.

Library client yang dimaksud adalah artifact berikut:

*   Java admin client - Maven artifact `org.keycloak:keycloak-admin-client`
*   Java authorization client - Maven artifact `org.keycloak:keycloak-authz-client`
*   Java policy enforcer - Maven artifact `org.keycloak:keycloak-policy-enforcer`
*   Java common classes yang digunakan oleh library client di atas - Maven artifact `org.keycloak:keycloak-client-common-synced`

Library client didukung dengan versi server NQRust-Identity terakhir yang didukung.

Library client mungkin tetap dapat bekerja dengan rilis server NQRust-Identity yang lebih lama, namun hal tersebut tidak dijamin dan tidak didukung secara resmi.

Mungkin diperlukan untuk memeriksa javadoc dari library client seperti Java admin-client untuk melihat endpoint dan parameter mana yang didukung dengan versi server NQRust-Identity tertentu. Untuk admin client, lihat "Kompatibilitas dengan server NQRust-Identity" di panduan NQRust-Identity admin client untuk catatan tambahan.
